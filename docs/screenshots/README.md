# Application screenshots

Captured from the current AyudaSys interface with a separate local demo database. Names, addresses, and programs are fictional. No real resident records were used.

| File                    | View                                                           |
| ----------------------- | -------------------------------------------------------------- |
| `dashboard.png`         | Overview, open program, totals, and recent release             |
| `household-census.png`  | Desktop household search and claim status                      |
| `community-map.png`     | Household map with OpenStreetMap attribution                   |
| `household-qr-stub.png` | Household details, enrollment, and printable stub              |
| `distribution.png`      | Actual stub-code lookup showing an already released enrollment |
| `mobile-census.png`     | Household cards at a 390px viewport                            |

Desktop captures use a 1440px viewport. The distribution screenshot uses actual code lookup, not a physical camera scan. The demo QR token is usable only against its local demo database and is not a production credential.

When updating screenshots, use an isolated demo database and keep map attribution visible. Keep these filenames or update the relative image links in the root README.
